## Отложенные задачи

Записаны по просьбе пользователя; начинаются только по его решению.

- [ ] DEP-01 — демо-стенд на офисном сервере с доступом из интернета через браузер (14.11.2026: «Запиши это как будущее задачи потом вернемся к нему»). Только синтетические данные до Pilot Gate. Предложение H: Linux-сервер, отдельный compose-файл (автоперезапуск, настоящее имя сайта, без `allow_tests`), скрипт для Linux, резервные копии по расписанию с выносом и `restore-check`, доступ через Cloudflare Tunnel + Access. Нужно от пользователя: домен и аккаунт Cloudflare. Открытый вопрос — допустим ли Cloudflare для закрытых данных (ADR-005). Источники и статусы — [research/04 §14](../../research/04-sources.md#14-офисный-сервер-и-доступ-из-интернета-14-ноября-2026).
- [ ] BOT-01 — бот расходов в мессенджере: скриншот поездки или строка «сумма, откуда → куда» → черновик транспортного расхода «на проверке», признаёт финансовый ответственный (14.11.2026: «Всю информацию которую здесь обсуждали сохрани в документах на будущее задачи»). Зависит от окна TRN-01–TRN-05 (не реализовано), шлюза и локальной модели ADR-005; порядок H: TRN с ручным вводом → бот без ИИ → распознавание после теста на реальных скриншотах. Подробно — [research/10 §3](../../research/10-bots-and-automations.md#3-bot-01--бот-транспортных-расходов).
- [ ] BOT-02 — бот группы: читает сообщения (русский, английский, узбекский, фото) и создаёт черновики задач `Task` для участника или общего списка; задачу получает исполнитель после подтверждения ответственным. Начать с явного режима «@бот задача»; вся переписка — только локальная модель. Подробно — [research/10 §4](../../research/10-bots-and-automations.md#4-bot-02--бот-группы-создающий-задачи).
- [ ] AUT-01 — автоматизации: сначала встроенные средства Frappe, внешний конструктор (кандидат Activepieces, MIT вне `ee`) — только связка с внешними сервисами. n8n в продукт не встраивается: лицензия запрещает коммерческое распространение. Подробно — [research/10 §6](../../research/10-bots-and-automations.md#6-aut-01--автоматизации).
- Общее для BOT-01/BOT-02: канал (Telegram, Max или веб-страница) зависит от страны работы — Telegram в России ограничивается с 02.2026; бот — тонкий адаптер, логика во Frappe. Открытые вопросы BQ1–BQ7 — [research/10 §7](../../research/10-bots-and-automations.md#7-открытые-вопросы).
- [ ] KB-01 — внутренняя база знаний команды «AV Wikipedia» на основе research/01–10 (14.11.2026: «Также хочется создавать свою базу знаний AV Wikipedia на основе того что уже изучали»; назначение — «Внутренняя база команды»; место хранения — «Потом подумаем над этим, скорее всего на сервере у компании»). Предложение H: статьи в Markdown по одной теме (термины, процесс проекта и приёмка, оборудование, экономика, референсные продукты, управление работами, платформа и лицензии, пресейл, ИИ и боты) со ссылками на research; доказательства и решения остаются в research, статья — читаемая сводка. Просмотр — Frappe Wiki v3 (MIT) на сервере компании вместе с DEP-01, закрытый раздел по ролям. Закрытые материалы компании — только на сервере компании, не в публичном репозитории. Подробно (разделы, варианты хранения, шаги KB-01.1–KB-01.6, вопросы KQ1–KQ6) — [research/11](../../research/11-knowledge-base.md); источники — [research/04 §17](../../research/04-sources.md#17-база-знаний-команды-14-ноября-2026).
