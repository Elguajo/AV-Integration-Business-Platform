# ADR-003 — Политика внедрения внешнего кода

Status: Accepted
Date: 2026-11-12

## Context
Пользователь хочет активно брать готовые продукты с GitHub и изучать чужие инструменты, оставаясь коммерческим продуктом. Проверка 12.11.2026 показала смешанные лицензии: Whiteboard и PDF из HeyPuter/everything — AGPL-3.0, tldraw, NocoBase, Directus — собственные или source-available лицензии (E5, research/03 §9).

## Decision
- Перед советом или внедрением — исследование: лицензия модуля, язык, активность, тесты, хранение данных. Не по памяти.
- MIT, Apache-2.0, BSD — использовать и копировать с уведомлением об авторстве.
- LGPL — как отдельная библиотека без изменения её кода.
- GPL, AGPL — код не копировать и не переводить построчно; допускается пересоздание поведения своими словами.
- Source-available, «Sustainable», «Enterprise», собственные соглашения — только по отдельному решению пользователя.
- Закрытые продукты (D-Tools, Jetbuilt, XTEN-AV) — документация, интерфейс как пользователь, публичный API, выгрузки; без декомпиляции и копирования текстов, дизайна, каталогов.
- Происхождение заимствований — `THIRD_PARTY_NOTICES.md` в корне и сообщение коммита; чужой модуль подключается через наш API, его хранилище заменяется адаптером; версии фиксируются.
- План по модулям Everything: Wiki и Projects (MIT) — адаптация; Field Service (MIT, alpha) — образец; Whiteboard и PDF (AGPL) — пересоздание на Excalidraw, React Flow, pdf.js, pdf-lib.

## Consequences
- Positive: юридически чистая кодовая база для продажи; быстрые заимствования там, где лицензия позволяет.
- Cost/risk: AGPL-модули приходится пересоздавать; это не юридическое заключение — финальная проверка в Q10.
- Revisit when: выбрана модель распространения (Q10) или продукт сам становится open-source.
